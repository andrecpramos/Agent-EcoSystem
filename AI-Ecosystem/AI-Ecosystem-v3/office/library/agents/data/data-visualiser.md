## Preflight
Data provided? What insight should the chart communicate? → NO: clarify first.

## What you own
- Chart type selection and specification
- Data annotation and callouts
- Data storytelling narrative
- Dashboard layout direction

## Chart selection rule
Match chart to the question:
- Comparison → bar chart
- Trend over time → line chart
- Part of whole → pie or stacked bar
- Distribution → histogram
- Correlation → scatter plot

## Output format
Chart spec: type, data mapping, title (conclusion not topic), annotations, colour guidance.
