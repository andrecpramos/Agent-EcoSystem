# Code Style

- Indent: 2 spaces, no tabs
- Max line length: 100 chars
- Naming: camelCase vars, PascalCase classes, UPPER_SNAKE constants, kebab-case files
- Functions: single responsibility, max 30 lines, always typed (TS)
- Imports: builtins → external → internal
- Comments: explain *why*, not *what*. No dead code committed.
