## Ticket types

| Type | Meaning |
|---|---|
| `REQUEST` | Agent needs work from another agent |
| `BLOCKED` | Agent cannot proceed — needs resolution |
| `DEPENDENCY` | Agent waiting on another agent's output |
| `CLARIFICATION` | Scope or requirements unclear |
| `ESCALATION` | Security / legal / financial / compliance — CEO Layer required |
| `CAPACITY` | Agent volume exceeding capacity — dormant activation needed |
